1. Systèmes de numération

Chapitre I

La base est le nombre de symboles utilisés par un système. Les humains utilisent la base 10 ; les machines la base 2 (bits). L’octal et l’hexadécimal sont des écritures compactes du binaire.

SystèmeBaseSymbolesChaque chiffre =
Décimal100–9—
Binaire20, 11 bit
Octal8 = 2³0–73 bits
Hexadécimal16 = 2⁴0–9, A–F4 bits (quartet)
Forme polynomiale. N = Σ Sᵢ · Baseⁱ, où Sᵢ est le symbole de rang i. Poids forts à gauche, poids faibles à droite.

2. Conversions

Chapitre I

Base B → décimal

Additionner chaque chiffre × son poids.

(1011)₂ = 8 + 0 + 2 + 1 = 11
(527)₈ = 5·64 + 2·8 + 7 = 343
(C4F)₁₆ = 12·256 + 4·16 + 15 = 3151

Décimal → base B

Divisions entières successives par B en gardant les restes, jusqu’à 0. Lire les restes du dernier au premier.

Exemple entier : 58 → binaire

Parties fractionnaires : multiplier par B

Partie entière : divisions. Partie fractionnaire : multiplications par B en gardant à chaque fois le chiffre entier, lu de haut en bas.

58.625 → 58 = 111010 ; 0.625×2 = 1.25 (1) → 0.25×2 = 0.5 (0) → 0.5×2 = 1.0 (1)
(58.625)₁₀ = (111010.101)₂

Certaines fractions ne se terminent pas : (0,15)₁₀ est cyclique en base 2, de période 1001.

4. Nombres signés : complément à 2

Chapitre I

Trois représentations : signe + valeur absolue, complément à 1 (C’1), complément à 2 (C’2). C’2 est la plus utilisée.

Règle. C2(N) = C1(N) + 1, où C1 inverse tous les bits. Le bit de poids fort est le signe : 0 = positif, 1 = négatif.

Décodage. Si le MSB vaut 0, lire normalement. S’il vaut 1, refaire le C2 pour obtenir la valeur positive, puis ajouter le signe moins.

Addition en C2 : additionner les deux nombres et rejeter la retenue finale.
11011 (−5) + 01001 (+9) = 1 00100 → +4

Sur n bits, C2 couvre −2ⁿ⁻¹ … 2ⁿ⁻¹−1 (8 bits : −128 … 127).

5. Codes numériques

Chapitre I

Un code pondéré attribue un poids fixe à chaque position (binaire naturel, octal, hexa, décimal, DCB). Un code non pondéré utilise un tableau de correspondances (Gray, ASCII).

Code DCB (Décimal Codé Binaire, 8-4-2-1)

Chaque chiffre décimal est codé sur un quartet (4 bits). (256.37)₁₀ = (0010 0101 0110 . 0011 0111). Les six quartets 1010 à 1111 sont interdits.

Addition en DCB. Additionner les quartets en binaire. Si la somme d’un quartet dépasse 9 ou génère un débordement, ajouter 6 (0110) à ce quartet.
Exemple 9 + 8 : 1001 + 1000 = 1 0001 → 0001 0001 + 0110 = 0001 0111 = 17

Code de Gray (binaire réfléchi)

Un seul bit change entre deux nombres consécutifs.

Recopier le MSB. Chaque bit suivant = bits binaires voisins différents → 1, identiques → 0 (XOR).

0101 → 0111

Gray → Binaire

Recopier le MSB. Chaque bit suivant = XOR du bit binaire précédent et du bit de Gray courant.

6. Algèbre de Boole

Chapitre II

Introduite en 1854 par George Boole (1815–1864). Claude Shannon l’a ensuite reliée à la conception des circuits, montrant qu’elle permet d’optimiser des circuits complexes. Variables et fonctions ne prennent que deux valeurs (0/1, vrai/faux).

À retenir. Une fonction de n variables a 2ⁿ combinaisons, donc sa table de vérité a 2ⁿ lignes. Le complément s’écrit avec une barre : si a = 0 alors a = 1.

7. Théorèmes

Chapitre II

De Morgan. On casse la barre, on change l’opérateur.

a·b = a + b    |    a+b = a · b

Valable pour n variables : x₀·x₁·…·xₙ = x₀ + x₁ + … + xₙ

Absorption

A + A·B = A
A·(A+B) = A
DémonstrationA + AB = A(1 + B) = A·1 = A

Allègement

A + A·B = A + B
A·(A + B) = A·B
DémonstrationA + AB = (A + A)(A + B) = 1·(A + B) = A + B

Consensus

x·a + x·b + a·b = x·a + x·b
(x+a)(x+b)(a+b) = (x+a)(x+b)
DémonstrationOn écrit ab = ab(x + x) = xab + xab. Alors xa + xab = xa(1+b) = xa, et xb + xab = xb.

8. Portes logiques

Chapitre II

Une porte est un circuit électronique réalisant une opération logique de base. Elle se décrit par un symbole graphique, une expression logique, une table de vérité et un chronogramme. Les portes à 2 entrées existent à 3, 4, … entrées (toujours une seule sortie) : AND₃ = a·b·c, OR₃ = a+b+c.

XOR = a·b + a·b : la sortie vaut 1 quand les entrées sont différentes. À plusieurs variables, XOR vaut 1 si le nombre de 1 est impair. XNOR vaut 1 quand les entrées sont égales.

9. Portes universelles : NAND et NOR

Chapitre II

{AND, OR, NOT} est un groupe d’opérateurs complet : toute fonction logique peut s’écrire avec. Il n’est pas minimal : De Morgan permet de remplacer OR par AND+NOT, ou AND par OR+NOT. {AND, NOT} et {OR, NOT} sont complets minimaux, tout comme {NAND} et {NOR} seuls.

CibleAvec NAND uniquementAvec NOR uniquement
NOT xNAND(x, x)NOR(x, x)
x · yNAND( NAND(x,y), NAND(x,y) )NOR( NOR(x,x), NOR(y,y) )
x + yNAND( NAND(x,x), NAND(y,y) )NOR( NOR(x,y), NOR(x,y) )

Exemple : XOR avec 4 portes NAND

f = x·y + x·y

Étage 1

n1 = NAND(x, y)

Étage 2

n2 = NAND(x, n1)
n3 = NAND(y, n1)

Sortie

f = NAND(n2, n3)

n1 = NAND(x,y); n2 = NAND(x,n1); n3 = NAND(y,n1); f = NAND(n2,n3) = x⊕y.

Autre exemple, F = (a+b)·(c+d) avec NOR uniquement : F = NOR( NOR(a,b), NOR(c,d) ). Chaque NOR interne donne le complément d’une somme ; le NOR externe les combine grâce à De Morgan : a+b + c+d = (a+b)(c+d).
